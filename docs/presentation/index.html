Problemstellung

  • Drohne als aktiver Schutz-Agent für eine Schafherde
  • Bedrohung: Wölfe, regelbasiert oder von Menschen gesteuert (Multiplayer)
  • Drohne darf nicht kollidieren — defensive Aktion: Scarer (Schall+Licht) zur Wolf-Furcht-Induktion
  • Constraint: muss in 3 Minuten trainiert werden können (Reset-Buffer 30s)

→ Klassisches Multi-Agent / Asymmetric-Roles Szenario mit physikalisch realistischer Drohnen-Dynamik (AR-Drone 2.0 Digital Twin)

Phase 4: Reward-Shaping (NEU)

Spec: "Je mehr Furcht die Wölfe, desto mehr Reward. Jedes überlebende Schaf ist ein Multiplikator. 5 min Episode. Strafe für getötete Schafe."

SignalWertTrigger
Δ Wolf-Furcht (per step)+4 × dFearWolf akkumuliert Furcht via Scarer
Wolf-Panic-Event+3.0einmalig pro Panic-Trigger
Schaf am Leben+0.0003 × N_sheepjeden FixedUpdate
Schaf-Tod−3.0sofort beim Catch
Drohne-Crash (Emergency)−1.0EndEpisode
Episode-Ende: Schafe gerettet+5 × N_survivedEndRound()
Perfect Defense× 1.5 multiplieralle Schafe überlebt
Schnell-Sieg-Bonus+0.05 / verbleibende Sekundenur bei Perfect Defense

Reward-Hacking Prevention

Gefahr: Agent könnte lernen, "Wölfe in Furcht halten" durch sehr aggressives Verhalten zu maximieren — Schafe als beifang opfern.

Schutz-Maßnahmen:

  • survivalRatio = sheepSaved / initialSheepCount
  • Episode-End-Bonus wird mit Lerp(0.2, 1.0, survivalRatio) skaliert
  • → wer alle Schafe verliert: 80% Reward-Penalty auf End-Bonus auch wenn Furcht hoch war
  • → wer alle rettet: voller Reward + 1.5× Multiplikator

// Survival-ratio shaping: pushes agent away from
// "trade sheep for fear-spam" exploits.
AddReward(endBonus * Mathf.Lerp(0.2f, 1f, survivalRatio));
EndEpisode();

Phase 4: GAIL Imitation-Learning

Reine Reward-Shaping würde Exploration zu langsam machen → wir injizieren menschliche Demonstrationen.


reward_signals:
  extrinsic:
    gamma: 0.99
    strength: 1.0
  gail:
    strength: 0.5             # weighted gegen extrinsic
    gamma: 0.99
    demo_path: Assets/Demonstrations/DroneSessions/
    use_actions: true         # GAIL diskriminiert auf (state, action)
    use_vail: false
  • Demo-Recording: via DemonstrationRecorder, 4 Hz Position-Logging
  • Replay-Pipeline: bestehende Multiplayer-Sessions → GAIL-Demos via app.linn.games shepherd.sessions API

Build & Deploy Flow

  1. Training auf BigOne erzeugt DroneCSI.onnx + DroneShepherd.onnx
  2. Models werden in Assets/Models/ committed (LFS optional)
  3. docker stack deploy -c deploy/swarm/shepherd-stack.yml shepherd
  4. Unity-Builder-Container startet auf BigOne (constraint: role=builder)
  5. Build-Output landet im NFS-Volume → automatisch auch sichtbar auf u-server
  6. nginx auf u-server serviced /shepherd/Build/*.br mit Brotli-Headern
  7. app.linn.games/shepherd/play lädt Unity-Instance über loader.js

Live-Demo Walkthrough
